MANUAL TÉCNICO Inicio

Astro es un framework moderno diseñado para crear sitios web rápidos, ligeros y altamente optimizados.

Su enfoque principal es reducir al mínimo la cantidad de JavaScript que se envía al navegador, lo que mejora el rendimiento general de las páginas.

🧠 Idea principal

Astro permite construir sitios web usando componentes reutilizables sin cargar código innecesario en el cliente.
