MANUAL TÉCNICO Inicio

Este manual esta creado con el objetivo de dejar como evidencia el aprendizaje para la construccion de un sitio web de manera estatico y multipagina. Su finalidas es proporcionar una guía sobre el proceso de instalacion, configuraciones, el desarrollo de paginas web utilizando Astro, tambien estilos en tailwind CSS y utilizando un poco del CSS tradicional

Tambien se proporcionara en este manual los conceptos fundamentales de cada paso a desarrollar, en el proceso vamos a utilizar buenas practicas de organizacion, reutilizacion de cogio y diseño responsivo para que se adapte a cualquier dispositivo.
